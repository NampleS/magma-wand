# 🪄 Magma 마법봉

[Magma](https://magma.com) 그림판에 **클립 스튜디오식 마법봉**을 붙여 주는 도구예요.
클릭한 곳과 비슷한 색으로 이어진 영역을 자동으로 선택하거나 바로 칠해요.

- **Magma 앱(Windows)**: 설치 한 번이면 평소처럼 Magma를 열 때 자동으로 켜져요.
- **크롬(웹)**: 확장 프로그램으로도 쓸 수 있어요.
- **자동 업데이트**: 새 버전이 나오면 알아서 받아요. 열려 있는 Magma에도 새로고침 없이 바로 적용돼요.

## 설치 (Windows)

1. **[MagmaWand-Setup.cmd 내려받기](https://github.com/NampleS/magma-wand/releases/latest/download/MagmaWand-Setup.cmd)**
2. 내려받은 파일을 더블클릭해요.
   - 크롬이 "위험할 수 있는 파일"이라고 하면 **계속**(또는 **유지**)을 눌러요.
   - 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요.
   - 서명되지 않은 개인 제작 파일이라 뜨는 경고예요.
3. 검은 창에서 "설치 완료!"가 나오면 끝이에요.

이제 **평소처럼 Magma를 열면** 그림판 오른쪽 위에 마법봉 패널이 떠요.

> 내려받기가 막히면: 시작 메뉴에서 **PowerShell**을 열고 아래 한 줄을 붙여 넣은 뒤 엔터를 눌러요.
> ```
> irm https://github.com/NampleS/magma-wand/releases/latest/download/install.ps1 -OutFile $env:TEMP\mw.ps1; powershell -ExecutionPolicy Bypass -File $env:TEMP\mw.ps1
> ```

### 크롬(웹)에서도 쓰려면

설치가 끝나면 크롬 확장 폴더가 준비돼 있어요(설치 창에 경로가 나와요).

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 그 폴더 선택

확장도 마법봉 코드는 자동으로 최신 버전을 받아요.

## 쓰는 법

1. 그림판 오른쪽 위 **마법봉** 패널에서 **🪄 마법봉 꺼짐** 버튼을 눌러 켜요.
2. 방식을 고르고 그림을 클릭해요.
   - **선택**: 선택 영역을 만들어요. 그다음 붓으로 칠하면 선택 안에만 칠해져요.
     - 클릭: 새로 선택 · **Shift**+클릭: 추가 · **Alt**+클릭: 빼기
   - **바로 채우기**: 클릭한 영역을 지금 색으로 바로 칠해요.
3. **Esc**를 누르면 꺼져요.

| 설정 | 하는 일 |
|---|---|
| 허용 오차 | 높을수록 비슷한 색까지 넓게 잡아요 (기본 10%) |
| 영역 확장 | 잡은 영역을 몇 픽셀 더 넓혀요. 선화 가장자리 밑까지 칠할 때 써요 (기본 1px) |

패널 제목을 끌면 옮길 수 있고, `–` 버튼으로 접을 수 있어요.

## 알아둘 점

- 화면에 **보이는 그림** 기준으로 잡아요(모든 레이어 참조). 세밀하게 잡으려면 100% 이상으로 확대하세요.
- 클릭 한 번에 0.5~2초쯤 걸려요. 그동안 Magma 올가미 도구가 대신 움직여요.
- Magma가 이미 켜져 있을 때 처음 설치하면, Magma를 한 번 다시 열어야 해요.
- 앱 연결은 이 컴퓨터 안에서만 쓰는 연결 통로(포트 39271)를 써요. Magma를 쓰는 동안만 열려 있어요.

## 지우기

**설정 → 앱 → 설치된 앱 → "Magma 마법봉" → 제거**
Magma 앱과 그림은 그대로예요.
