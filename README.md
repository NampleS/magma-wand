# 🧩 Magma Extension

[Magma](https://magma.com) 그림판에 **클립 스튜디오·포토샵 기능**을 더해 주는 확장이에요.
클릭한 곳과 비슷한 색의 영역을 **픽셀 단위로 정확하게** 선택하거나 바로 칠해요. 화면을 축소해서 봐도 실제 그림 픽셀 기준으로 계산해요.

- **Magma 앱(Windows)**: 설치 한 번이면 평소처럼 Magma를 열 때 자동으로 켜져요.
- **크롬(웹)**: 확장 프로그램으로도 쓸 수 있어요.
- **자동 업데이트**: 새 버전이 나오면 알아서 받아요. 열려 있는 Magma에도 새로고침 없이 바로 적용돼요.

## 설치 (Windows)

1. **[MagmaExtension-Setup.cmd 내려받기](https://github.com/NampleS/magma-wand/releases/latest/download/MagmaExtension-Setup.cmd)**
2. 내려받은 파일을 더블클릭해요.
   - 크롬이 "위험할 수 있는 파일"이라고 하면 **계속**(또는 **유지**)을 눌러요.
   - 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요.
   - 서명되지 않은 개인 제작 파일이라 뜨는 경고예요.
3. 검은 창에서 "설치 완료!"가 나오면 끝이에요.

이제 **평소처럼 Magma를 열면** 왼쪽 도구 막대에 새 도구들이 생겨요.

> 내려받기가 막히면: 시작 메뉴에서 **PowerShell**을 열고 아래 한 줄을 붙여 넣은 뒤 엔터를 눌러요.
> ```
> irm https://github.com/NampleS/magma-wand/releases/latest/download/install.ps1 -OutFile $env:TEMP\mw.ps1; powershell -ExecutionPolicy Bypass -File $env:TEMP\mw.ps1
> ```

### 크롬(웹)에서도 쓰려면

설치가 끝나면 크롬 확장 폴더가 준비돼 있어요(설치 창에 경로가 나와요).

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 그 폴더 선택

확장도 자동으로 최신 버전을 받아요.

## 쓰는 법

### 도구 폴더 (클립 스튜디오처럼)
왼쪽 도구 막대의 비슷한 도구를 **폴더**로 묶었어요. 오른쪽 아래 작은 삼각형이 폴더 표시예요. 누르면 마지막에 쓴 도구가 골라지고, 오른쪽에 같은 폴더 도구들이 펼쳐져요.

| 폴더 | 들어 있는 도구 |
|---|---|
| 선택 | 사각형 선택 · 타원 선택 · 올가미 선택 · **퀵 마스크**(새 도구) |
| 자동 선택 | 🪄 마법봉 · 빠른 선택 |
| 브러시 | Magma 브러시 · 고급 브러시 |
| 블렌드 | 블렌드 · **블러**(새 도구) · 리퀴파이 |
| 도형 | 사각형 · 타원 · 도형 |
| 화면 | 손 · 화면 회전 · 확대·축소 |
| 자 | 원근 격자 · **대칭 자**(새 도구) |

Magma 단축키(B, M, L, Space 등)는 그대로 쓸 수 있고, 폴더 버튼 그림도 따라 바뀌어요. Edit → Application settings → Toolbar(Customize Toolbar)에서 도구 순서를 바꿔도 폴더가 따라가요.


- **마법봉 (W)**: 클릭한 곳과 비슷한 색의 영역을 선택하거나 바로 칠해요.
- **빠른 선택 (Shift+W)**: 포토샵의 빠른 선택처럼 브러시로 문지르면, 문지른 곳의 색들을 기준으로 영역이 넓어져요(색 경계에서 멈춤). 문지르는 동안은 내 화면에만 파란 미리보기가 보이고, 손을 떼면 선택이 확정돼요. 선택이 있으면 자동으로 추가, **Alt**로 빼기, **[ ]**로 브러시 크기를 조절해요.

다른 도구를 고르면 자동으로 꺼져요. 설정은 오른쪽 도구 설정 칸에 나와요.

| 설정 | 하는 일 |
|---|---|
| 선택 모드 | Magma 선택 도구와 같아요 (새 선택 / 추가 / 빼기 / 교차). **Shift**+클릭은 추가, **Alt**+클릭은 빼기 |
| 동작 | **선택**: 점선 선택 영역을 만들어요 · **채우기**: 클릭한 영역을 지금 색으로 바로 칠해요 |
| 참조 | **모든 레이어**: 보이는 그림 전체 기준 · **현재 레이어**: 지금 고른 레이어만 기준 |
| 범위 | **이어진 곳만**: 클릭한 곳과 이어진 부분만 · **전체 같은 색**: 떨어져 있어도 보드 전체에서 같은 색이면 모두 (클립 스튜디오·포토샵의 '인접' 끄기) |
| 허용 오차 | 높을수록 비슷한 색까지 넓게 잡아요 (기본 10) |
| 영역 확장 | 잡은 영역을 몇 픽셀 더 넓혀요. 선화 가장자리 밑까지 칠할 때 써요 (기본 1) |
| 빈틈 닫기 | 선화가 이 픽셀 수의 두 배까지 끊겨 있어도 새지 않게 잡아요(클립 스튜디오 '틈 닫기'). 끊긴 끝을 곧은 선으로 이어 막아요. 0이면 꺼짐 (기본 0) · '이어진 곳만'일 때만 써요 |

슬라이더는 끌거나, 마우스 휠을 굴리거나, 숫자를 눌러 직접 입력할 수 있어요.

### 멈추면 도형으로 보정 (클립 스튜디오·프로크리에이트 QuickShape)
선을 긋다가 **펜을 떼지 않고 1초 멈추면**, 그은 선과 가장 비슷한 깔끔한 선으로 바뀌어 보여요. 손을 떼면 그 모양으로 그려져요. **필압은 원래 그은 자리 그대로** 옮겨져요.
- 알아보는 모양: **직선 · 원호 · 곡선 · 원 · 타원 · 삼각형 · 사각형 · 다각형**(변 길이는 제각각이어도 돼요. 거의 직각인 사각형은 반듯하게, 거의 수평이면 수평으로).
- 곡선은 여러 번 얽힌 낙서가 아니면 **베지어 곡선 한 개**로 단순하게 정리돼요.
- 멈춘 채 펜을 움직이면 그 도형을 **돌리고 키울 수** 있어요(직선은 끝점이 펜을 따라와요).
- Magma 연필·브러시·지우개·블렌드·올가미 채우기와 고급 브러시에서 써요. 대칭 자가 켜져 있으면 건너편도 같이 보정돼요.
- 보정된 획은 되돌리기 한 칸이에요. 끄려면 **Window 메뉴 → 그리기 → 멈추면 도형으로 보정**.

### 대칭 자 (자 폴더, 클립 스튜디오처럼)
보드에 **끌어서 대칭 축**을 만들면, 그다음부터 그린 획이 축 건너편에도 그대로 그려져요.
- **가운데 동그라미**를 끌면 축을 옮기고, **네모 점**을 끌면 돌려요(Shift: 15°씩). 빈 곳을 끌면 새 축.
- 설정 칸: **대칭** 켜기/끄기 · **선 개수**(2~16) · **선대칭**(켜기 = 거울, 4개면 상하좌우 / 끄기 = 가운데를 중심으로 빙 돌린 모양) · 세로 / 가로 / 보드 가운데 · 자 지우기.
- Magma의 연필·브러시·지우개·블렌드·올가미 채우기와 고급 브러시에서 써요. Shift+클릭 직선도 대칭으로 이어져요.
- 축은 **내 화면에만** 보이고 보드마다 따로 기억해요. **Ctrl+Z 한 번**에 원본과 건너편 획이 함께 되돌아가요. 다만 Magma 되돌리기는 15칸까지라, Magma 브러시로 그리면 건너편 획마다 한 칸씩 써서 거슬러 갈 수 있는 획 수가 줄어요(고급 브러시는 획 하나 = 한 칸).

### 사용자 지정 UI: 패널 옮기기·붙이기·탭 (클립 스튜디오처럼)
도구 막대·색상환·브러시·브러시 목록·레이어가 각각 **패널**이 됐어요. 처음에는 원래 Magma 화면처럼 오른쪽 한 줄(색상환 / 브러시·브러시 목록 탭 / 레이어)과 왼쪽 도구 막대로 놓이고, 패널마다 위에 얇은 이름표가 생겨요.
- 이름표 오른쪽의 **−**로 접어서 이름표만 남기고(다시 누르면 펼침), **×**로 닫아요(Window 메뉴에서 다시 열기).
- **도구 막대**는 넓히면 아이콘이 여러 줄로, 화면 위·아래에 얇게 붙이면 가로로 늘어서요.
- 패널 안이 넘치면 Magma 레이어 목록과 같은 얇은 스크롤바가 생겨요.
- **이름표를 끌어** 원하는 곳에 놓아요. 끄는 동안 놓일 자리가 파랗게 보여요.
  - 다른 패널의 **가운데** → 같은 자리를 나눠 쓰는 **탭**으로 합쳐져요(탭을 눌러 전환).
  - 다른 패널의 **위·아래·왼쪽·오른쪽 가장자리** → 그 옆에 붙어요.
  - **화면 맨 가장자리**(위·아래·왼쪽·오른쪽) → 화면 전체 기준으로 새 줄·칸이 생겨요.
  - 그림판 위 빈 곳 → **떠 있는 창**이 돼요. 떠 있는 창은 가장자리·꼭짓점을 끌어 크기를 바꿔요.
  - 탭이 여럿인 묶음에서 **탭 하나를 끌면** 그 패널만 떼어 내요.
- 패널 사이 **경계선을 끌면** 창 크기는 그대로 두고 두 패널의 비율만 바뀌어요.
- 위쪽 막대의 **Window** 단추(창 모양 아이콘)에서:
  - 패널 보이기·숨기기
  - 화면 모드(Super Simple / Simple / Full), 브러시 목록, 두 줄, 색상환 모양(사각형/삼각형). 색상환 옆에 있던 ⚙ 레이아웃 단추는 여기로 옮겼어요.
  - **배치 처음으로**: 지금 모드의 원래 배치로
  - **사용자 지정 UI 끄기**: 원래 Magma 화면으로 완전히 되돌려요(다시 켤 수도 있어요).
- 배치는 화면 모드마다 따로 기억돼요. Super Simple 모드와 Tab으로 UI를 숨긴 동안은 Magma 원래 화면을 그대로 쓰고, 돌아오면 내 배치로 돌아와요.
- 문제가 생기면(Magma 업데이트와 충돌 등) **화면 배치만** 원래 Magma 화면으로 돌아가요. 다른 기능은 그대로 쓸 수 있고, Window 메뉴에서 다시 켤 수 있어요.

### 영어 화면
Magma 계정 언어가 한국어가 아니면 확장이 더한 글자(패널 이름·설정·메뉴·알림)도 영어로 나와요. **Window → 확장 언어**에서 자동 / 한국어 / English를 직접 고를 수도 있어요.

### 묶음 되돌리기 (Ctrl+Z 한 번 = 동작 하나)
여러 레이어 함께 변형·이동·속성 바꾸기, 블러, 투명색 지우기처럼 Magma Extension 동작 하나가 Magma 되돌리기를 여러 칸 쓰면, **바로 다음 Ctrl+Z 한 번**(또는 위쪽 되돌리기 단추)으로 그 칸들을 한꺼번에 되돌려요. **Ctrl+Shift+Z·Ctrl+Y**(다시 하기)도 한 번에 다시 해요.
- Magma 자신의 되돌리기 단추를 칸 수만큼 대신 누르는 방식이라, 손으로 여러 번 누른 것과 결과가 똑같아요. 되돌리는 동안(칸마다 0.3초쯤) 화면 아래에 안내가 떠요.
- 그 뒤에 다른 걸 그리거나 바꿨으면 Ctrl+Z는 평소처럼 한 칸씩이에요.
- Magma 되돌리기는 보드마다 15칸까지라, 묶음이 15칸을 넘으면 앞부분은 되돌릴 수 없어요(그래서 함께 고르는 레이어 수에 한도가 있어요).

### 페인트통: 빈틈 닫기·영역 확장/축소·투명색
- **Close gap**(빈틈 닫기)을 올리면 Magma Extension이 대신 칠해요. 선의 끊긴 끝을 찾아 그 거리 안의 다른 선까지 **곧은 선으로 이어** 막은 뒤 안쪽을 채워요. 틈 자리는 직선으로 깔끔하게 끊기고, 나머지는 원래 선을 그대로 따라가요.
- 설정 칸의 **확장/축소** 줄(Close gap 아래)로 칠할 영역을 n픽셀 넓히거나(+, 선화 밑까지) 좁혀요(−). 빈틈 닫기와 같이 써도 돼요.
- **투명색(C)**을 고른 상태로 누르면 그 영역을 지워요(clear와 같음).
- 셋 다 안 쓰면(Close gap 0, 확장/축소 0, 투명색 아님) Magma 페인트통 그대로예요. Magma Extension이 칠할 때는 페인트통 설정(대상 레이어·허용 오차·Contiguous·Invert·fill/clear·Opacity)을 그대로 읽어 올가미 채우기 한 번으로 칠해요(되돌리기 한 칸).
- Mode가 opacity·smart이거나 Target layer가 above·below면 빈틈 닫기·확장/축소 없이 Magma 그대로 칠해요(투명색은 그때도 clear로 지워요). **Anti-alias**를 켜 두면 가장자리를 부드럽게 칠해요(지우기일 때는 되돌리기 2칸).

### 퀵 마스크 (선택 폴더)
지금 선택이 **빨갛게** 보이고, 브러시로 칠해서 선택을 넓히거나(칠하기) 지워서 줄여요(Alt를 누른 채 칠하기, 또는 설정 칸의 '선택 빼기'). 클립 스튜디오의 퀵 마스크와 같아요.
- **Enter**(또는 '선택으로 만들기')를 누르거나 **다른 도구로 바꾸면** 칠한 모양이 Magma 선택이 돼요(되돌리기 한 칸). 칠하는 동안은 내 화면에서만 보이고 다른 사람에게 가는 게 없어요.
- **Ctrl+Z**는 퀵 마스크 안에서 칠한 획을 하나씩 되돌려요. **Esc**(또는 '처음으로')는 처음 선택으로 돌려요. **[ ]**로 브러시 크기.
- 선택이 없을 때 쓰면 빈 상태에서 칠해 새 선택을 만들어요.
- **투명색(C)**을 고른 상태면 브러시가 지우개가 돼요(선택 빼기). Alt는 그 반대.

### 블러 (블렌드 폴더)
문지른 곳을 흐리게 해요. 설정 칸에서 **브러시 크기**, **강도**(흐림 반경, 클수록 많이 번짐), **밀도**(한 번 지날 때 섞는 양, 클수록 빨리 흐려짐)를 정해요.
- 문지르는 동안은 내 화면에만 미리 보여요. 손을 떼면 ① 바뀐 사각형을 잠깐 비우고 ② 흐린 결과를 붙여 넣어요(되돌리기 **두 칸**, 다른 사람 화면에서는 잠깐 깜빡일 수 있어요).
- 현재 레이어만 흐려요. 선택 영역이 있거나 글자 레이어·투명 잠금 레이어에는 쓸 수 없어요. **[ ]** 로 크기, Esc로 취소.

### 자유 변형: Ctrl+T, Ctrl을 누른 채 점 끌기
Magma 변형(Ctrl+T)에서 **Ctrl을 누른 채 8개 점 중 하나를 끌면** 그 점만 움직여 그림을 비틀어요(클립 스튜디오 자유 변형). 다른 점은 그대로예요. 손을 떼면 원래 변형 모드로 돌아와요.
- Magma 변형 칸의 4가지 모드(크기·기울이기·원근·왜곡)도 그대로 쓸 수 있어요.

### Ctrl+레이어 썸네일 클릭: 레이어 내용 선택
레이어 목록의 **작은 그림(썸네일)을 Ctrl+클릭**하면 그 레이어 그림 모양대로 선택이 잡혀요(우클릭 → Select layer content와 같아요). 지금 레이어는 바뀌지 않아요.

### Alt+레이어 사이 클릭: 클리핑 마스크 (포토샵처럼)
레이어 목록에서 **Alt를 누른 채 두 레이어 줄 사이**에 마우스를 대면 파란 선이 보여요. 누르면 **위 레이어가 아래 레이어에 클리핑**돼요(다시 누르면 풀려요). 지금 고른 레이어는 바뀌지 않아요.

### 여러 레이어 함께 고르기·변형 (클립 스튜디오처럼)
레이어 목록에서 레이어 **이름 쪽을 Ctrl+클릭**하면 지금 레이어와 함께 고를 수 있어요(파란 띠로 표시). **Shift+클릭**은 지금 레이어부터 그 레이어까지 한꺼번에, **그냥 클릭**하면 함께 고르기가 풀려요.
- **변형(Ctrl+T)·이동(V)**: 지금 레이어를 변형하거나 옮기면 함께 고른 레이어도 같이 움직여 보여요. 다른 도구를 고르거나 다른 레이어를 누르는 순간 함께 고른 레이어에도 **똑같이** 들어가요(크기·회전·이동·뒤집기·기울이기·원근·왜곡 모두).
- **눈(보이기)**: 함께 고른 레이어 중 하나의 눈을 누르면 나머지도 같이 꺼지고 켜져요.
- **속성**: 레이어 칸 위쪽에서 지금 레이어의 **불투명도·합성 모드·투명 픽셀 잠금·잠금·클리핑**을 바꾸면, 손을 뗀 뒤 함께 고른 레이어에도 똑같이 맞춰져요.
- 레이어마다 Magma 변형이 한 번씩 들어가요 → **되돌리기도 레이어마다 한 칸**이에요. 되돌리기가 15칸이라 한 번에 13개까지 고를 수 있어요.
- 적용하는 동안(레이어 하나에 0.5초쯤) 화면 아래에 안내가 뜨고 잠깐 입력이 막혀요.
- **선택 영역이 있으면 선택 안쪽만** 함께 변형·이동돼요(사각형·타원·올가미 선택 모두). Magma는 변형을 확정할 때 선택도 같이 움직이기 때문에, 함께 고른 레이어마다 ① 선택 해제 ② 원래 선택을 올가미로 다시 긋기 ③ 변형을 해요 → **되돌리기가 레이어마다 3칸**이라 함께 고른 레이어는 4개까지예요.
- 여러 조각(또는 구멍)으로 된 선택, 잠긴 레이어가 섞였을 때는 지금 레이어만 바뀌어요. 다른 사람 레이어는 함께 고를 수 없어요.
- 미리보기 동안 함께 고른 레이어는 내 화면에서만 잠깐 숨겨지고(개인 보이기), 끝나면 원래대로 돌아와요. 미리보기에서는 레이어 순서와 무관하게 위에 겹쳐 보여요.

### 텍스트: 한글
Magma 글꼴 중 한글이 들어 있는 건 **Paperlogy**와 **Syongsyong**이에요. 다른 글꼴(기본 Montserrat 등)에는 한글 글자가 없어서 네모(□)로 나와요.
- 텍스트 도구 칸의 **한글** 줄에서 두 글꼴을 바로 고를 수 있어요. **자동**을 켜 두면 텍스트 도구를 처음 고를 때 기본 글꼴을 한글 글꼴로 맞춰 줘요.
- 이미 쓴 글자의 글꼴을 바꾸려면 글자를 고른 뒤(Ctrl+A 등) 글꼴 단추를 눌러요.
- **내 컴퓨터 글꼴…**: 컴퓨터에 설치된 글꼴(맑은 고딕·궁서 등)로 글자를 **그림으로** 만들어 지금 레이어에 붙여요. 다른 사람에게도 같은 모양으로 보이지만, 붙인 뒤에는 글자를 고칠 수 없어요(Magma 글자 레이어에는 Magma 글꼴만 쓸 수 있어서). 붙인 직후 이동 도구로 옮길 수 있어요.

### 브러시 크기: Ctrl+Alt 끌기 (클립 스튜디오 방식)
크기를 바꿀 수 있는 모든 브러시 — Magma의 연필·브러시·지우개·블렌드·리퀴파이, 새로 생긴 빠른 선택·고급 브러시·블러·퀵 마스크 — 에서 **Ctrl+Alt를 누른 채 그림판을 끌면** 브러시 크기를 바로 바꿀 수 있어요.
- 원의 중심에서 마우스까지가 브러시 반지름이에요. 끄는 동안 원과 크기 숫자가 보여요(내 화면에만).
- 다시 조정할 때는 **지금 크기의 원이, 지난번 조정을 끝낸 방향에 마우스가 오도록** 나타나요. 그래서 누르는 순간 크기가 튀지 않고 이어서 조절돼요.
- 손을 떼면 Magma의 Size 칸에 한 번만 들어가요. 조정하는 동안 그림이 그려지거나 스포이트로 색이 바뀌지 않아요.
- Ctrl+Alt를 누른 채 여러 번 빠르게 끌어도 매번 바로 앞 크기에서 이어서 바뀌고, 키를 떼면 마지막 크기가 들어가요.

### 투명색 (C 키)
색 견본(검정·파랑 네모) 아래의 **체크무늬 견본**이 투명색이에요. 누르거나 **C 키**로 '지금 색 ↔ 투명색'을 바꿔요(C는 원래 Magma의 댓글 키였는데 투명색 전환으로 바뀌어요).
- 투명색일 때 Magma **브러시·연필**을 고르면 자동으로 Magma **지우개**가 돼요. 투명색을 끄면 원래 도구로 돌아와요.
- **고급 브러시**는 그 질감 그대로 지워요. 손을 떼면 ① 지운 부분을 감싸는 사각형을 잠깐 비우고 ② 지운 결과를 붙여 넣어요 — 되돌리기 **두 칸**이고, 다른 사람 화면에서는 아주 잠깐 깜빡일 수 있어요. 선택 영역이 있을 때는 고급 브러시로 지울 수 없어요.
- 다른 색을 고르면(스포이트·색상환·X 키) 투명색은 저절로 꺼져요.

### 스포이트 고리
스포이트(I 키, 또는 Alt를 누른 채)로 그림판을 **누르고 있는 동안** 커서 둘레에 고리가 떠요. 클립 스튜디오처럼 **위쪽 반은 지금 고르는 색, 아래쪽 반은 원래 색**이고, 누른 채 움직이면 실시간으로 바뀌어요.
- Alt 스포이트는 Magma에서 실제로 색을 고르는 도구(브러시·지우개·페인트통 등)에서만 고리가 떠요. 올가미·선택·이동처럼 색을 안 쓰는 도구에서는 뜨지 않아요.

### Ctrl+Shift 클릭: 그림이 있는 레이어 찾기
그림판에서 **Ctrl+Shift+클릭**하면 그 자리에 그림이 있는 맨 위 레이어를 찾아요(클립 스튜디오와 같은 기능).
- **내 레이어**면 바로 그 레이어로 바뀌어요.
- **다른 사람 레이어**면 레이어 목록이 그 줄까지 내려가고 노란 테두리로 반짝여요.
- 레이어를 찾기만 하고 그림판에는 아무것도 그리지 않아요.
- 맨 아래 3개 레이어 중 보드 전체를 투명한 곳 없이 꽉 채운 레이어는 배경 종이(클립 스튜디오의 '용지')로 보고 잡지 않아요. 배경에 실수로 그리지 않게 하려는 거예요.

### Alt+Delete: 채우기
**Alt+Delete**로 선택 영역(선택이 없으면 보드 전체)을 지금 색으로 채워요. Magma에는 같은 명령이 없어서 새로 만들었어요.
- Magma 올가미 채우기로 한 번 칠해요(되돌리기 한 칸). 선택 영역 밖은 칠하지 않아요.
- 투명색일 때는 그 영역을 지워요.

### Space+끌기: 화면 이동 · 패널 넘기기
- 마법봉·빠른 선택·고급 브러시·블러·퀵 마스크를 쓰는 중에도 Magma 도구처럼 **Space를 누른 채 끌면** 화면이 움직여요.
- 그림판 둘레의 **위아래로 넘어가는 칸**(레이어 목록·도구 설정 칸·브러시 설정 창·메뉴 등) 위에서 Space를 누른 채 끌면, 그 칸이 손으로 밀듯 위아래로만 넘어가요(관성 없음). Space를 누르면 넘길 수 있는 칸 위에서 손 모양 커서가 보여요. 레이어나 단추를 누르지 않아요.

### 단축키 바꾸기
**Edit → Application settings → Shortcuts → Tools**의 "마법봉 (Magic Wand)" / "빠른 선택 (Quick Selection)" / "고급 브러시" / "블러" / "퀵 마스크"(기본 **Q**, 다시 누르면 선택으로 반영하고 나가요) / "대칭 자" / "투명색 전환" 줄에서 다른 도구처럼 바꿀 수 있어요(+ 를 누르고 원하는 키 조합). Save를 눌러야 저장돼요. 한글 입력 상태에서도 동작해요.

### 선택 범위 확장/축소
**Edit → Invert selection 아래**의 "선택 범위 확장…" / "선택 범위 축소…"를 누르고 픽셀 수를 넣으면 돼요. 마법봉이 아닌 다른 도구로 만든 선택에도 쓸 수 있어요.
- 화면을 회전·뒤집기한 상태에서는 아직 쓸 수 없어요.
- 선택 영역 일부가 화면에 보여야 해요(위치 확인용).

### 고급 브러시 (클립 스튜디오 브러시 불러오기)
**브러시 폴더**의 **고급 브러시**(단축키 Shift+B)로 클립 스튜디오 브러시 파일(.sut)을 불러오거나, **＋ 새 브러시 (프리셋)**으로 바로 쓸 브러시를 만들어 그릴 수 있어요.

- **프리셋 68종, 10갈래로 분류**: 연필·스케치 / 잉크·펜 / 마커 / 드라이(목탄·파스텔) / 수채 / 물감(유화·구아슈) / 섞기·문지르기 / 에어브러시 / 질감·특수 / 장식·자연.
  - **＋ 새 브러시 (프리셋)** 창: 왼쪽에서 분류를 고르거나 이름으로 찾고, 카드마다 **실제 그리기 엔진으로 그린 획 미리보기**와 한 줄 설명이 나와요(섞기 브러시는 빨강·파랑 띠 위에서 끌리는 모습).
  - 드라이 재료: HB·4B·8B 연필, 색연필, 연필 눕혀 칠하기, 목탄 연필, 버드나무 목탄, 압축 목탄, 목탄 옆면, 콩테, 소프트·오일 파스텔, 크레용, 분필, 갈필(마른 붓), 스펀지, 점묘, 마른 먹, 마른 수채, 종이결·캔버스결 칠, 그런지 등.
  - **내 브러시 목록**도 분류별로 묶여 보이고(머리를 누르면 접기·펴기, 기억됨), 줄마다 획 미리보기가 있어요. 분류는 ⚙ 설정 → 이름·관리에서 바꿀 수 있어요. '빈 브러시'로 끝 모양만 골라 시작할 수도 있어요.
- **결 방식 '깊이'**(텍스처 탭): 종이 결을 높낮이로 써요. 살살 칠하면 종이 돌기 끝에만 묻고, 세게·여러 번 칠할수록 골까지 채워져요 — 실제 연필·목탄·파스텔처럼. (예전 '무늬 덮기'는 무늬를 위에 얹는 방식)
- **물감 탭**(⚙ 설정): 물감·수채를 진짜처럼 만드는 세 가지예요.
  - **붓털**: 털마다 물감을 따로 묻혀서 끊김 없는 결이 남아요. 물감 마름과 같이 쓰면 길게 그을수록 털이 하나씩 말라 갈라져요(유화·아크릴·구아슈의 마른 끝). 둥근 붓/평붓, 털 수, 결 세기, 털마다 색 차이.
  - **두께감·광택**: 물감이 두껍게 올라온 것처럼 붓 자국 굴곡에 왼쪽 위 빛과 그림자를 넣어요(임파스토). 팔레트 나이프는 가장자리에 물감 둑이 생겨요.
  - **젖은 물감(수채)**: 물이 닿은 가장자리가 또렷하고 구불구불해지고, 풀림을 올리면 젖은 종이처럼 번지고, 안료 알갱이가 종이 골에 가라앉아요.
  - 새 프리셋: 유화 임파스토, 마른 붓(스컴블), 구아슈 둥근 붓, 유화 블렌더, 수채 세필·글레이즈·알갱이. 유화·평붓·구아슈·아크릴·나이프·수채는 새 방식으로 다시 만들었어요(전에 만든 브러시는 그대로라, 새 느낌을 쓰려면 프리셋으로 새로 만들어 주세요).
- **물감 마름·흩어짐**(획 탭): 그 길이만큼 그으면 붓의 물감이 줄어 털 자국만 남아요(갈필). 흩어짐은 도장 자리를 조금씩 흔들어 가장자리가 기계적으로 반복되지 않게 해요.
- 연필은 마르게: 심 끝 윤곽이 종이에 걸려 들쭉날쭉하고, 종이 골에는 거의 묻지 않아요(텍스처 탭 '골에 남는 가루'로 조절). 캔버스 천 결은 실마다 굵기·자리가 다른 촘촘한 평직으로 새로 만들었어요(타일처럼 보이지 않게).
- 새 기본 텍스처: 드로잉지 결·목탄지·중목 종이·사포·그런지(이음매 없음), 새 끝 모양: 흑연·목탄 끝·목탄 옆면·파스텔 덩이·마른 붓털·납작 붓털·레이크·스펀지·점묘·풀·털 가닥.
- **⚙ 브러시 설정**(브러시 이름을 두 번 눌러도 열려요): 클립 스튜디오 보조 도구 상세처럼 항목별로 바꿔요. 떠 있는 작은 창이라 열어 둔 채로 그어 보며 맞출 수 있어요(제목을 끌어 옮기기).
  - 크기(+필압·속도·무작위 효과) · 잉크(불투명도·흐름·안티에일리어스) · **색 혼합**(블렌드 / **물감 섞기**: 물감량·물감 농도·색 늘이기, 섞을 밑색 = 현재 레이어 또는 보이는 그림) · 끝 모양(경도·두께·각도와 필압/진행 방향/무작위·반전·순서) · 획(간격·손떨림 보정·**입/출** 가늘게·리본) · 스프레이(입자 크기·수·모임) · 텍스처(농도·배율·반전·도장마다) · 색 흔들기(색상·채도·명도) · 이름·복제
- **물감 섞기**: 그으면 붓에 밑색이 묻어 끌려와요. 물감량 0이면 색 없이 밑색만 문지르는 손끝이 돼요. 색은 **실제 물감처럼 감산 혼합**돼요(노랑+파랑 = 초록, 회색 탁색이 아님).
- **합성 모드**(잉크 탭): **물감 겹치기** = 투명한 물감을 덧칠한 것처럼 화면에 보이는 아래 그림(다른 레이어 포함)과 감산 혼합돼요(노랑 수채 위 파랑 = 초록, 수채 프리셋 기본값). 곱하기 = 같은 레이어 그림과 곱해져 겹칠수록 어둡고 탁해져요(마커). 지우기 = 그 브러시 모양 그대로 지우개. (되돌리기 한 칸)
  - 물감 겹치기는 칠하는 순간 보이던 아래 색을 그 레이어에 섞어 넣어요. 나중에 아래 레이어를 옮기거나 숨기면 섞인 색은 그대로 남아요.
- **투명 픽셀 잠금** 레이어에서는 있는 그림 위에만 칠해지고 바깥은 그대로 투명해요(블러도 같음, 되돌리기 2칸이지만 Ctrl+Z 한 번).
- **2중 브러시**(.sut): 두 번째 끝 모양으로 찍은 무늬로 획을 깎아 거친 질감을 만들어요. 보호된 소재면 '끝 모양 바꾸기'의 '2중 브러시 끝 모양' 칸에 기본 모양이나 PNG를 넣어요.
- **필압 곡선**(크기 탭): 살살 눌러도 진하게 ↔ 세게 눌러야 굵게. **농도 강조**(텍스처 탭): 종이 결을 더 또렷하게.
- **수채 경계**(설정 창 탭): 물이 마르며 가장자리에 물감이 고인 것처럼 테두리 안쪽이 진해져요. 그리는 동안에도 결과와 똑같이 보여요. 수채 프리셋은 곱하기 + 수채 경계 + 젖은 물감이 켜져 있어요.
- **B 키**: Magma 브러시를 쓰는 중에 B를 한 번 더 누르면 고급 브러시로, 또 누르면 Magma 브러시로 번갈아 바뀌어요.
- 기본 텍스처는 이음매 없는 종이·수채 종이·캔버스 천·노이즈·거친 결·빗금·망점이에요. 기본 끝 모양(연필·분필·붓털·수채 등)이 좋아지면 예전에 만든 브러시도 자동으로 새 모양으로 바뀌어요(프리셋 설정값은 그대로라, 새 프리셋 값을 쓰려면 프리셋으로 새로 만들어 주세요).
- **Alt**를 누른 채 누르면 스포이트(투명한 곳은 투명색), **Shift+클릭**은 지난 획 끝에서 곧은 선, 선택 영역이 있으면 **선택 안에만** 칠해져요.

1. 오른쪽 설정 칸의 **＋ 브러시 가져오기 (.sut)** 로 브러시 파일을 골라요(여러 개 한 번에 가능). 불러온 브러시는 이 컴퓨터에 저장돼요.
2. 끝 모양 이름 옆에 ⚠ 표시가 있으면, 그 브러시의 끝 모양·텍스처 그림이 **보호된 소재**라 직접 꺼낼 수 없다는 뜻이에요.
   - **끝 모양 바꾸기**에서 **기본 모양**(원·부드러운 원·사각형·납작붓·연필·분필·스프레이·붓털·수채·구름·물감 튀김·별·반짝이·하트·잎·삼각형·눈송이)을 고르거나,
   - 클립 스튜디오에서 그 소재를 캔버스에 붙여 **PNG로 저장**한 뒤 **PNG 고르기**로 넣어 주세요(미리보기로 어떤 그림인지 보여 줘요).
   - 텍스처도 같은 곳에서 기본 텍스처(종이·캔버스 천·노이즈·빗금·망점)로 바꾸거나 없앨 수 있어요.
3. 그리면 그리는 동안은 내 화면에만 보이고, **손을 떼는 순간 보드에 들어가요**(되돌리기 한 칸). 다른 사람에게는 손을 뗀 뒤에 보여요.
   - 그리는 동안 보이는 모습은 **들어갈 결과와 같아요**: 밑 레이어에 그리면 위 레이어 그림 아래로 보이고, 투명색은 지운 자리에 아래 그림이 드러나 보이며, 곱하기·투명 픽셀 잠금·레이어 불투명도·클리핑·선택 영역·수채 경계·두께감도 그대로 반영돼요.
   - **숨겨진 레이어·잠긴 레이어**에서는 획을 시작하지 않고 바로 알려 줘요(페인트통·블러·글자도 같음).
4. **투명색(C 키)** 으로 바꾸면 같은 브러시가 그 질감 그대로 지우개가 돼요(위의 '투명색' 참고).

- .sut에서 읽는 것: 크기·흐름·불투명도·두께·간격의 필압/속도/무작위 효과(곡선 포함 — 속도는 아주 빠르게 휘두를 때만 크게 바뀌고, 첫 점은 속도·방향을 안 뒤에 찍어 시작이 뭉툭해지지 않아요), 새 클립 스튜디오에서 저장한 .sut의 곡선도 바르게 읽어요(예전 버전으로 가져와 곡선이 깨진 브러시는 고를 때 알려 주고 곧은 곡선으로 그려요 — .sut를 다시 가져오면 원래대로), 끝 모양 여러 장(순서·무작위·좌우 뒤집기), 회전(고정·선 방향·무작위), 스프레이, 텍스처, 리본 끝 모양, 색 흔들기, 손떨림 보정, 입·출, **색 혼합(블렌드·물감 섞기)**.
- .sut의 합성 모드 번호는 아직 다 몰라서 '보통'으로 그려요(지우개 브러시면 ⚙ 설정 → 잉크 → 합성 모드 '지우기').
- 크기는 설정 칸 슬라이더, **[ ]** 키, **Ctrl+Alt 끌기**로 바꿀 수 있어요. Esc를 누르면 긋던 획을 취소해요.
- 획 하나가 보드 크기 그림 한 장으로 들어가서, 보통 펜보다 보내는 데이터가 조금 많아요.

### 레이어 속성 (경계 효과 — 내 화면에만)
브러시 목록(1~6번 칸) 끝의 **레이어 버튼**을 누르면, 그 아래 브러시 설정 자리에 클립 스튜디오처럼 **레이어 속성**이 떠요. 다시 누르거나 브러시 칸을 누르면 브러시 설정으로 돌아가요(Edit 메뉴의 "레이어 속성 (내 화면)…"으로도 열 수 있어요).
- **경계 효과(테두리)** 를 켜고 두께(1~100px), 색, 안티에일리어싱, 흐리기(0~20px)를 정해요. 바꾸는 즉시 보여요. 레이어를 바꾸면 그 레이어의 속성으로 바뀌어요.
- 보드에는 평범한 레이어 그대로라 **다른 사람에게는 보이지 않아요.** 그리는 도중에도 테두리가 바로 따라와요.
- 위에 있는 레이어가 덮은 곳에서는 테두리도 가려져요(실제 레이어 효과처럼). 화면 회전·확대도 그대로 맞춰요.
- 레이어마다 따로, 보드마다 저장돼서 나중에 다시 들어와도 이어져요. 끄려면 레이어 속성에서 '켜짐'을 눌러 '꺼짐'으로 바꿔요.

### 작업 기록 (되돌리기 15번 넘게 거슬러 가기)
Magma 되돌리기는 서버가 보드마다 15번까지만 관리해서, 이걸 늘리면 보드가 망가질 수 있어요. 대신 **작업 기록**이 몇 분마다 바뀐 레이어를 **이 컴퓨터에만** 저장해 둬요(다른 사람에게 가는 데이터 없음).

1. **Edit → 작업 기록 (내 컴퓨터)…** 을 눌러요. 저장된 시점들이 썸네일과 함께 보여요.
2. 원하는 시점을 누르면 레이어 목록이 펼쳐져요. 되살릴 레이어의 **복사**를 눌러요.
3. **Edit → Paste on new layer**를 누르면 그 시점의 레이어가 **새 레이어로, 원래 자리에** 들어가요. 지금 그림은 그대로라서 비교해 보고 필요 없는 쪽을 지우면 돼요.

- 그리는 중에는 저장하지 않고, 손을 쉬는 사이에 바뀐 레이어만 저장해요. **지금 저장** 버튼으로 바로 저장할 수도 있어요.
- 보드마다 최근 60개 시점, 모든 보드를 합쳐 300MB까지 보관하고 오래된 것부터 지워요. **자동 기록** 체크를 끄면 멈춰요.
- 크롬과 Magma 앱은 기록을 따로 보관해요. 브라우저 데이터를 지우면 기록도 지워져요.

## 알아둘 점

- **실제 픽셀 기준:** 화면이 아니라 보드의 실제 그림 픽셀로 계산해요. 확대·축소와 상관없이 결과가 같고, 테두리를 픽셀 그대로 따라가요(시험 보드에서 수십만 픽셀 영역도 오차 0픽셀 확인). 그림을 읽는 건 내 컴퓨터 안에서만 일어나서 다른 사람에게 가는 데이터가 없어요.
- 선택할 때는 Magma 올가미 선택의 **안티에일리어스를 잠깐 끄고** 그었다가 1초쯤 뒤 원래대로 돌려 놓아요(마법봉을 쓰는 동안 Anti-alias 칸은 숨겨져요). 가장자리가 반투명하지 않고 픽셀 단위로 딱 맞게 잡혀요.
- **전체 같은 색**은 계산이 빠르고(보드 전체도 수십 ms), Magma에는 올가미 한 번만 보내요. 손으로 올가미를 한 번 긋는 것과 비슷한 양이라 다른 사람에게 렉을 주지 않아요.
- 테두리가 아주 복잡하면(조각·구멍이 수백 개) Magma 올가미 한 번에 담을 수 있는 점 수(약 4,500개)를 넘어서, **아주 작은 조각부터 빼고** 선택해요. 그럴 때는 설정 칸 아래에 "작은 조각 N개는 뺐어요"라고 알려 줘요.
- 아주 드물게, 모서리로만 맞닿은 1픽셀짜리 구멍은 Magma가 선택을 정리하면서 메워 버려요(Magma 자체 처리라 피할 수 없어요).
- **채우기**는 Magma 올가미 채우기를 쓰는데, 이 도구는 가장자리를 살짝 부드럽게 칠해서 테두리 픽셀 일부가 완전히 진하지 않을 수 있어요(칠할 곳·안 칠할 곳은 정확해요).
- 화면을 **회전·뒤집기**한 상태에서는 예전처럼 화면 기준으로 계산해요(이때는 확대해서 쓰는 게 좋아요).
- **데스크톱 앱 광고:** 크롬에 [Better Magma](https://chromewebstore.google.com/detail/ddhihheflhonhdfohkbdfkdlcalkajbj) 확장이 설치돼 있으면, Magma Extension 실행기가 같은 효과를 Magma 데스크톱 앱에도 적용해요(앱을 연 직후 화면이 한 번 새로고침돼요). 광고 차단은 Magma 이용 약관과 계정 정책에 따라 불이익이 있을 수 있으니 본인 판단으로 쓰세요.
- 클릭 한 번에 0.1~0.8초쯤 걸려요(테두리가 복잡할수록 길어요). 그동안 Magma 올가미 도구가 대신 움직이고, 마우스·펜 입력은 잠깐 막혀요.
- 마법봉 한 번 = Magma 되돌리기 한 칸이에요(올가미를 한 번만 그어요).
- 구멍이 있거나 떨어진 조각을 선택하면 조각들을 잇는 가는 점선이 보일 수 있지만, 실제 선택 모양에는 영향이 없어요.
- Magma가 이미 켜져 있을 때 처음 설치하면, Magma를 한 번 다시 열어야 해요.
- 앱 연결은 이 컴퓨터 안에서만 쓰는 연결 통로(포트 39271)를 써요. Magma를 쓰는 동안만 열려 있어요.
